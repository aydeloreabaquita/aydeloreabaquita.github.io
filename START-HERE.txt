AYDELORE PORTFOLIO — ANIMATED MORPHIC GLASS REVISION

This version keeps your black, pastel-pink, and pastel-violet colors.
It adds moving background circles and clearer translucent glass panels.

INSTALLATION
1. Extract the ZIP.
2. Copy all files inside the folder.
3. Paste them into your existing aydeloreabaquita.github.io folder.
4. Do not delete the hidden .git folder.
5. Preview index.html with Live Server.
6. Publish with:

   git add -A
   git commit -m "Apply animated morphic glass theme"
   git push origin main

The circle movement is made with CSS, so no extra library or JavaScript is needed.
Visitors who have reduced-motion enabled will see stationary circles.
